# 트러블슈팅

## 1. Apache → Tomcat 프록시 502/타임아웃
- **증상**: Web 서버에서 리버스 프록시 설정 후 응답 없음
- **원인**: WAS 보안그룹에 8080 인바운드 미허용
- **해결**: WAS SG에 8080 허용 (최종: `pc-sg-nlb` 참조로 한정)
- **교훈**: 프록시 문제는 Apache 설정보다 **네트워크 경로(SG/NACL/라우팅)** 부터 확인

## 2. LB 재생성 후 설정 드리프트
- **증상**: 로드밸런서 삭제·재생성 후 Web이 존재하지 않는 NLB DNS로 프록시
- **원인**: Parameter Store 값이 갱신되지 않은 채 남아 있었음
- **해결**: EC2·LB·파라미터를 처음부터 재구축하고, 리소스 변경 시 파라미터 동기화를 절차에 포함
- **교훈**: 콘솔 수동 작업은 상태 추적이 안 됨 → IaC 필요

## 3. Tomcat 10 전환 시 javax → jakarta
- **증상**: Tomcat 10.1에서 팀 포크 WAR 배포 실패
- **원인**: Tomcat 10부터 Servlet API 패키지가 `jakarta.*`로 변경, 프로젝트는 `javax.servlet` 기반
- **해결**: 코드 수정 금지 조건 때문에 최종은 **Tomcat 9 + Java 17**로 확정

## 4. AMI로 띄운 인스턴스에서 EBS 마운트 실패
- **증상**: 새 인스턴스 부팅 시 데이터 볼륨 미마운트 / 부팅 지연
- **원인**: `fstab`에 디바이스 이름(`/dev/xvdb` 등)을 사용 → Nitro에서 이름이 달라짐
- **해결**: UUID + `nofail` 옵션으로 등록
